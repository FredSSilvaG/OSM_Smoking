# Influence of Smoking on the Human Ocular Surface Microbiome and Tear Proteome

This repository contains the scripts used for data processing, statistical analysis, and visualization
for the manuscript:

**“Influence of smoking on the human ocular surface microbiome and tear proteome.”**

The repository is intended to support reproducibility of the analyses reported in the manuscript.

---

## Repository Scope

- Analysis of ocular surface microbiome data
- Analysis of tear proteome data
- Comparison between smokers and non-smokers
- Statistical analysis and figure generation for publication

 **Raw data are not included** due to ethical and privacy constraints.
